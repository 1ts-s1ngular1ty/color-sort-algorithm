# Color Sort Algorithm (Prototype)

## Package Link
[pypi.org](https://pypi.org/project/color-sort-algorithm/)

## Install
```
pip install color_sort_algorithm
```

## Usage Example
```python
from color_sort_prototype import ColorSort
unsortedData = []
sortedData = ColorSort(unsortedData, True, True) # First True/False = Ascending/Descending order, Second True/False = Numerical/Alphabetical sorting
```
